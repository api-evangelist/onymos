# Onymos

> Onymos sells "Features-as-a-Service": pre-built, pro-code application components that enterprise
> engineering teams install into their own web, mobile and IoT applications instead of building
> commodity functionality from scratch. Onymos runs on a "No-Data Architecture" — the software executes
> inside the customer's own cloud or on-premises environment and Onymos states it never stores, sees or
> accesses customer data. Onymos Inc. is headquartered at 1600 El Camino Real, Suite 280, Menlo Park,
> CA 94025, and states it is SOC 2 certified and HIPAA compliant.

## What Onymos publishes, and what it does not

- There is NO OpenAPI, Swagger, GraphQL, AsyncAPI, gRPC or WSDL contract. Probed /openapi.json,
  /swagger.json, /api-docs, /api/openapi.json and /graphql on onymos.com (404) and on api.onymos.com
  (503 on every path).
- There is NO MCP server and NO A2A agent card.
- There is NO public pricing page, NO status page, NO changelog, NO deprecation policy and NO published
  rate limit.
- There is NO first-party SDK in any public package registry. Onymos components are licensed
  commercially and can be delivered as source code; there is no `npm install` line to follow.
- Onymos's own API-docs landing page is broken: https://onymos.com/developers/api-docs/ and
  https://onymos.com/platforms/api-docs/ redirect to each other in an infinite loop. The per-feature
  reference pages below are the working entry points.

## The one REST API

- [Onymos DocEnhance API](https://onymos.com/api/onymos-docenhance-endpoints/): asynchronous document
  image enhancement. POST /api/enhance accepts a base64 image plus a preset (document, auto-crop, photo,
  watermark) and returns a result_url; GET /api/enhance/results/{UUID} collects the finished image.
  Authorised with an `onymosIesAuthToken` request header. The reference does not state the base host.

## Component reference (client-side SDK surface)

- [Access](https://onymos.com/api/onymos-access-functions/): OAuth 2.0 social sign-in via Apple, Facebook
  and Google — login, logout, getAuth, listenForAuth, signup, resetPassword.
- [Biometrics](https://onymos.com/api/onymos-biometrics-functions/): isAvailable, authenticate.
- [DataStore](https://onymos.com/api/onymos-datastore-functions/): addData, insertData, updateData,
  deleteData, getData, listenForData, selectFile, uploadFile, searchFile, getFile.
- [Media](https://onymos.com/api/onymos-media-functions/): select, upload, stopUpload, getThumbnail,
  getMediaType, search.
- [Chat](https://onymos.com/api/onymos-chat-functions/): getList, getMessages, listenForMessages,
  loadMessagesPreviousSet, sendMessage.
- [Notification](https://onymos.com/api/onymos-notification-functions/): register, unregister, notify,
  receive, badge management.
- [Contacts](https://onymos.com/api/onymos-contacts-functions/): getList, loadNextSet, loadSpecificSet.
- [Location](https://onymos.com/api/onymos-location-functions/): getLocation, geofence create/delete/
  activate, isLocationInGeoFence, closestGeoFence.
- [DeepLink](https://onymos.com/api/onymos-deeplink-functions/): createDeepLink, onDeepLink.
- [Share](https://onymos.com/api/onymos-share-functions/): showSocial.
- [Payments](https://onymos.com/onymos-payments-api/): makePayment, makeSubscriptionPayment,
  cancelSubscription, payout, registerAccount — brokering Stripe, PayPal, Apple and Google.
- [DocID](https://onymos.com/api/onymos-docid-functions/): analyze, listModels — client-side document
  classification.
